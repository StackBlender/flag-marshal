# Support

Start with the [CLI reference](docs/cli.md) and the [changelog](CHANGELOG.md).
Please post only sanitized, intentionally public material in this repository.

## Where to ask

| Need | Channel |
| --- | --- |
| Reproducible bug (crash, wrong exit code, broken output) | [Bug report form](https://github.com/StackBlender/flag-marshal/issues/new?template=bug.yml) |
| A flag reported wrongly, missed, or given the wrong confidence | [Detection problem form](https://github.com/StackBlender/flag-marshal/issues/new?template=detection.yml) |
| Feature request, new provider or language, documentation | [Feature request form](https://github.com/StackBlender/flag-marshal/issues/new?template=feature-request.yml) |
| Security concern | [GitHub private vulnerability reporting](https://github.com/StackBlender/flag-marshal/security/advisories/new) |

Flag Marshal is free, community-supported software. Support here does not include
guaranteed response times, individual debugging, a version-support commitment, or an
SLA.

## Safe reports

Provide a minimal reproduction whenever possible. **Replace real flag keys with
placeholders** — flag keys can reveal unreleased features. Remove secrets,
credentials, personal or customer data, proprietary source, and sensitive logs before
posting. If safe sanitization is not possible, do not attach the material publicly.
